
## 5. 功能自检（浏览器里过一遍）

| 步骤 | 预期 |
|---|---|
| 打开 `/` | 看到讨论列表（状态徽章、专家头像色块） |
| 点「发起讨论」，输入**自由话题**（别用样例） | 生成出的嘉宾姓名/职业/立场与话题强相关 |
| 点「确认阵容，进入演播厅」 | 主持人开场 → 专家逐字发言（不是一次性刷出） |
| 看右侧「专家状态」 | 待机 / 准备发言 / 发言中 三态切换 + 一句公开思考摘要 |
| 看右侧「共识与分歧」 | 随发言**逐步增长**（不是结束才出现） |
| 看右侧「现场 Transcript」 | 姓名 + 职业/Title + 色块；**没有"举手"等内部事件字样** |
| 结束后 | 主持人自然语言总结，**页面上没有任何 JSON 原文** |
| 再开一场不同话题，两边来回切 | 两场内容互不串台（并行隔离） |
| 拖动窗口到很窄 / 超宽 | 三档布局切换，页面本身不滚动，各区域内部滚动 |
