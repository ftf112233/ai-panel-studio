# 真实 DeepSeek 联调实录（证据留档）

> 目的：回答三个问题——① 自由主题是否真的动态生成阵容；② 主持人是否真在追问/总结、发言是否非机械轮流；③ 功能是否齐备。
> 环境：deepseek-chat，真实 API，无任何人工修饰。脚本：`backend/smoke_real.py`（可复现）。

## 实录一：自由输入主题「普通人现在该不该把闲钱投入黄金」

### 1. 阵容生成（全部由模型按此话题实时产出，非预制）

| 角色 | 姓名 | 职业 / Title | 立场 |
|---|---|---|---|
| 主持人 | 陈静 | 主持人 | — |
| e1 | 王振华 | 贵金属投资 / 管理过 20 亿黄金 ETF、经历两次金价腰斩的基金经理 | 当前金价已透支降息预期，现在入场是高位接盘 |
| e2 | 刘明远 | 宏观经济研究 / 研究央行购金与去美元化十年的首席宏观分析师 | 央行购金是结构性趋势，配置 5%-10% 正当其时 |
| e3 | 赵慧敏 | 家庭理财规划 / 服务过 300 个中产家庭、见过追高被套的独立理财顾问 | 关键不是该不该买，而是应急储备和负债有没有理清 |
| e4 | 孙立群 | 金融消费者保护 / 处理过上百起贵金属投资纠纷的公益律师 | 实物金与纸黄金的隐性成本和骗局风险被严重低估 |

颜色由代码从调色板分配（`#e8590c / #1971c2 / #2f9e44 / #9c36b5`），保证不重复。

### 2. 讨论过程（节选，含主持人串联与追问）

```
---- 第 1 轮 ----
[主持人·opening]   金价一路冲高，后台好多观众在问：现在手里那点闲钱，到底该不该追一把黄金？
[举手] 王振华
[主持人·transition] 王振华这话够直接——现在进场就是接盘，2020年追高的人套了两年。
                    那我想请刘明远接一下：您研究央行购金十年，这波央行买盘到底是结构性支撑，还是也撑不住高位？
[反驳] 刘明远
[主持人·transition] 好，赵慧敏这句话点到了要害——配5%到10%是压箱底，一把梭才是接盘。
                    那我们就顺着这个往下问孙立群，普通人真去动手买，坑到底藏在哪儿？
[举手] 孙立群

---- 第 2 轮 ----
[补充] 赵慧敏
[主持人·transition] 慧敏这句"拿救命钱去赌"说得够狠，正好接上立群刚提的隐性成本和骗局风险。
                    那我想追问立群：普通人真去买实物金或纸黄金，最容易被忽略的成本和坑到底是什么？
[举手] 孙立群
[主持人·transition] 孙律师这句"跑三家银行才出手"太真实了…那我想问赵慧敏老师，
                    在急着变现这个前提下，您觉得家庭账本得先理到什么程度，才轮得上谈买黄金？
[举手] 赵慧敏
```

**结论**：主持人串联语 100% 引用上一位的真实发言；每次发言者都由 DirectorAgent 依据 transcript 选择，序列为 王振华 → 刘明远 → 孙立群 → 赵慧敏 → 孙立群 → 赵慧敏，**不是 A-B-C-D 循环**，且无连续同人。

### 3. 实时共识 / 分歧（随发言增量增长）

- 1 条共识 → 2 条 → 3 条 → 4 条 → 5 条（逐步累积）
- 分歧示例：`王振华 vs 刘明远：金价是否提前透支降息预期、追高者是否会被套`

### 4. 主持人总结（自然语言，非 JSON）

> 真正的分歧是时机而非价值：王振华说金价已透支降息预期、现在入场就是高位接盘，刘明远则坚持央行购金是结构性趋势、5%-10%配置正当其时；而赵慧敏和孙立群把问题拉回现实——先理清应急储备和负债，再算清实物金和纸黄金的隐性成本。下一步很具体：先查清自家应急金和负债，若确有余力，再按刘明远说的比例分批小额配置，并找孙立群提醒的隐性成本清单逐项核对。

## 实录二：自由输入主题「30 岁转行做 AI 还来得及吗」

### 发言顺序与动作

```
[举手] 张伟 → [反驳] 李静 → [反驳] 张伟
```

### 共识 / 分歧（真实姓名，无占位词）

- 共识：`张伟所说的 12 个站得住的项目经验是有效的，李静对此不否认`
- 共识：`张伟承认李静所说的工程底子是真门槛，但认为它筛的是没被上线捶过的人，而不是 30 岁的人`
- 分歧：`李静（互联网行业） vs 张伟（人工智能）：工程底子能否靠补课速成`
- 分歧：`张伟（人工智能） vs 陈晓峰：年龄是否是转行做 AI 的门槛`

### 发言长度（验证 1-2 句）

```
张伟  (65字)  年龄不是门槛，我招的 40 个里 12 个是 30 岁后转的…陈晓峰把年龄当门槛，是拿没做过项目的人当样本。
李静  (67字)  张伟说的12个站住的我不否认，但两次烂尾恰恰栽在工程底子上…这是筛人的硬门槛。
张伟 (103字)  陈晓峰，40个里28个扛过完整上线…李静说的门槛是真门槛，但它筛的是没被上线捶过的人，不是30岁的人。
```

## 本次联调修掉的一个真实缺陷

初版实录（黄金那场）中，分歧字段出现了「发言者」「该发言者」「尚未表态的其他人」这类**占位词**。原因是 InsightAgent 的 user 模板只传了发言正文，没有传说话人是谁。

**修法**：`insight.v1.json` 的 user 模板改为「最新发言（{speaker}）」，并在 system 里硬性要求 a/b 必须使用嘉宾真实姓名、禁止占位词；`Orchestrator` 调用时传入 `姓名（职业）`。修复后的实录二已全部是真实姓名。
